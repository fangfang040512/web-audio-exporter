# 音频导出工作台

一个不用装扩展的网页工具，做三件事：**解析网页音轨**、**录制标签页声音**、**从本地视频里抽音频**。全部在浏览器本地完成，不上传任何数据。

## 为什么有这个东西

原本是一个 Chrome 插件（[web-video-audio-exporter](https://github.com/Changhuaishui/web-video-audio-exporter)），靠 `activeTab` 注入脚本读页面数据。网页没有这个权限，所以这里换了三条路：

| 插件能力 | 网页版怎么实现 |
| --- | --- |
| 自动读 `__playinfo__` | 提供一段控制台脚本，一键把数据/地址复制到剪贴板，粘回来解析 |
| `tabCapture` 录标签页 | 用 `getDisplayMedia` 捕获标签页音频，选「Chrome 标签页」并勾选共享音频 |
| 插件内探测媒体元素 | 直接粘贴媒体直链，支持一次贴多条 |
| — | 新增：本地视频解码抽音轨，支持 WAV / MP3 导出 |

## 三个面板

### 01 音轨解析

粘贴哔哩哔哩的 `__playinfo__` JSON、整页源码，或者任意媒体直链（每行一个，可批量）。

- 按 **无损 > 杜比 > 标准 > 码率** 排序，标出推荐项
- 显示码率、编码、容器格式、CDN 域名
- 可试听、复制地址、直接导出
- 遇到防盗链会生成带 `Referer` 的 `curl` / `aria2c` 命令

怎么拿数据：点页面上的「复制控制台脚本」，粘到 B 站控制台回车，脚本会自动取 `window.__playinfo__`；取不到就退回到页面已加载的 `.m4s` 媒体地址。

### 02 实时录音

浏览器不允许网页读取其他标签页的媒体状态，所以这里用屏幕捕获接管系统音频。

- 实时波形 + 频谱底纹 + RMS 电平表
- 支持暂停、续录
- 输出 WebM/Opus（192 kbps），可一键转 WAV
- 每条录音带波形缩略图

开始后在系统弹窗里选 **Chrome 标签页**，务必勾上 **「同时共享标签页的音频」**，否则录出来是静音。

### 03 本地提取

把本地视频或音频拖进来，浏览器内解码。

- 波形上拖拽框选片段，或用输入框精确到 0.01 秒
- 选区可直接试听，不用先导出
- 输出 WAV（16/24-bit PCM）或 MP3（320/192/128 kbps）
- 支持重采样、单双声道转换
- 导出前实时估算文件体积，超 200MB 会标红
- 多文件队列，串行解码避免内存爆掉

## 快速开始

不需要安装任何东西，也没有构建步骤。

```bash
# 方式一：双击 start.bat（Windows，自动起服务并打开浏览器）

# 方式二：手动起一个静态服务
python -m http.server 8898 --bind 127.0.0.1
# 然后打开 http://127.0.0.1:8898/index.html
```

直接双击 `index.html` 也能用，但 `file://` 下「另存为」对话框可能不弹出、PWA 无法安装，建议走本地服务。

## 使用要点

**B 站音轨下不来怎么办**

音轨地址带 referer 防盗链，浏览器直连必然 403。点音轨右侧的终端图标，复制 `curl` 命令（Windows 10+ 自带 curl），在保存目录打开终端执行。命令里已经带好了 `Referer` 和 `User-Agent`。

**导出位置**

- 弹系统「另存为」：你选哪就在哪
- 没弹窗：落在浏览器下载目录（默认 `C:\Users\<你>\Downloads`）
- 浏览器出于安全只给文件名，不给完整路径，想确认就用 `chrome://downloads` 查

**大文件**

整个解码过程在内存里跑，超过 1 小时的音频建议先截取片段。导 WAV 尤其吃空间，1 小时 48kHz 立体声约 1.2GB，选 MP3 只要 86MB。

## 浏览器要求

Chrome / Edge 116 及以上。用到 `getDisplayMedia`、`MediaRecorder`、`OfflineAudioContext`、`showSaveFilePicker`，Firefox 和 Safari 部分功能不可用。

├── assets

## 开发

```bash
npm test        # 13 个解析用例，覆盖文件名清洗、扩展名推断、音轨排序、协议校验
```

外观配置存在 `localStorage["wae:prefs"]`，只记主题色、明暗模式、动效开关和导出参数，音频数据一律不落地。

右上角调色盘可以切换深色 / 浅色 / 跟随系统，6 组预设主题色加任意自定义取色，动效可一键关闭。

## 已知限制

- 不绕过 DRM、加密、付费墙或登录限制
- 浏览器跨域策略决定了 B 站音轨无法直连下载，只能走命令行
- 录屏是实时录制，1 小时的视频就要录 1 小时，有直链优先走解析
- MKV 等容器浏览器解不了，需要先转码
- `blob:` 地址和纯画面无音轨的媒体不能直接导出
